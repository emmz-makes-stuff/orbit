- **13.1:** `splitExtras` refuses any two extras where one lies within the other, whatever their
  modes. This is Emmz's ruling, reversing §10's ro-in-ro allowance (a symlink in the outer copy can
  redirect the inner one). Updated: the vm-access "Overlapping extras" scenario, the README bullet,
  and the test table (`ro inside ro` added; `TestNestedReadOnlyExtrasAllowed` removed).
- **13.2:** `runSync` places the copies under the home the VM reports, then calls `checkAgainstMounts`.
  That function lists the machine's live mounts and refuses any copy whose VM path overlaps one,
  naming both and saying to run `orbit rebuild`. Tests cover an extra switched from rw to ro, and a
  new ro extra inside a live rw mount. Mutation check: removing the call fails the test.
- **13.3:** `addPath` skips sockets and records them under the declared path, not the
  symlink-resolved one (`/tmp`, not `/private/tmp`). `copyExtras` now returns `(skipped, err)`, and
  create and sync warn "skipped socket …". The test uses a real unix socket in `/tmp`, because macOS
  caps socket paths at 104 bytes and `t.TempDir` paths are longer.
- **13.4:** a setup.sh `Stat` error other than not-exist fails provisioning ("can't check for
  .orbit/setup.sh") before the marker is written.
- **Gotcha:** a multi-substitution `perl -0pi` edit of copy.go wrote garbage, because `\|\|` in a
  pattern delimited by `|` became alternation. I restored the file from HEAD (no §13 work in it yet)
  and redid the edit with the Edit tool. Avoid `|` delimiters when the pattern contains `||`.
