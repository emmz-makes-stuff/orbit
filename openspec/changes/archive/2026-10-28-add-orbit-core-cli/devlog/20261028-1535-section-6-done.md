# §6 done: create, provision and attach

<!-- Section: 6 · Tasks: 6.1–6.3 · Base: 55eaa77 -->

- `internal/cli/root.go`: bare `orbit` runs `Getwd` → `config.Canonical` → `List` → `Resolve`.
  - **Overlap:** refuse, naming each workspace and its VM, and suggest running from inside one or
    `orbit destroy`.
  - **Create:** create, then attach.
  - **Found:** attach. Before attaching, start the VM if needed, and warn if
    `/var/lib/orbit/provisioned` is missing (skipped right after a create).
  - **Token:** read from the Keychain. If none is stored, or the Keychain can't be read, warn and
    attach without it. Then `ExecShell` with `orb.ForwardEnv(Environ(), {CLAUDE_CODE_OAUTH_TOKEN})`.
  - **SSH agent:** checked (`ssh-add -l`) once per invocation, before create or attach.
  - A `List` failure is wrapped as "could not reach OrbStack: …".
- `internal/cli/create.go`: `planFor` validates everything before `Create`.
  - The workspace path must be mountable, and the config must load.
  - Each extra must exist and must not overlap the workspace, in either direction (carried over from
    §2).
  - Then the VM is created with mounts in the order `[workspace, rw extras…]`.
  - Then provisioning runs:
    1. Find the default user (`id -un`).
    2. Copy the read-only extras.
    3. Pipe `baseline.sh` to `bash -s` (falling back to `sh -s`) as root.
    4. Run `.orbit/setup.sh` **in place** from the mount (`bash <ws>/.orbit/setup.sh`, so the script
       can find its neighbours) as the default user, with `-w <ws>`.
    5. Write the marker.
  - Script output streams to the terminal. A failure names the script and its exit code, but orbit
    exits 1 (not the script's code), keeps the VM, and suggests `orbit rebuild` / `orbit destroy`.
- `internal/cli/copy.go`: **the tar stream is built in-process with `archive/tar`, not Mac `tar`.**
  That gives exact symlink control and needs no extra Mac tool. A top-level symlinked extra is
  dereferenced (carried over from §2), symlinks inside directories are kept, and Mac uid/gid are zeroed.
  In the VM, a root `sh -c 'rm -rf -- <paths>; tar -C / -xpf -; chown -R -h <user> -- <paths>'`
  clears the stale copy first. That's the D8 replace semantics, which §7's `sync` reuses.
- `Deps` gained `Environ` and `SSHAgentHasKeys`. The test harness now uses the real `os.Stat` and
  real temp dirs. The `vm` simulator in `root_test.go` recognises each command orbit sends.
- Tests: 28 in `internal/cli`. Mutation check: disabling the SSH warning, or swallowing a setup
  failure, makes `TestSSHAgentWarning` / `TestSetupFailureKeepsVMAndNamesScript` fail. Both were
  restored.
