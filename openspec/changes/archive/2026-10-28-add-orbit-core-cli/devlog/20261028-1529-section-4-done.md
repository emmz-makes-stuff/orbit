- `internal/orb`:
  - `Client` has List, Create, Start, Stop, Delete, Run and ExecShell. The `CLI` implementation sits
    over `orbctl`, and the process runner and exec are injected for tests.
  - `New()` returns `ErrNotInstalled`, which says to run `brew install orbstack`.
  - Errors from non-streaming calls carry orbctl's stderr (`orbctl start: <msg>`). `Run` streams
    instead, and returns `*ExitError{Code}`.
  - Create args are `create --isolated --forward-ssh-agent --mount P:P … [--cpus/--memory/--disk]
    <distro> <name>`.
  - `ExecShell` runs `syscall.Exec(orbctl, ["orbctl","run","-m",m,"-w",dir], env)`.
  - `ForwardEnv(env, vars)` sets the vars and merges them into `ORBENV`, keeping existing entries
    without duplicates. §6 uses it for `CLAUDE_CODE_OAUTH_TOKEN`.

  `Shells` / `Created`. `OnRun` controls Run's outcome, and `Errs[op]` injects failures.
  `ExecShell` returns nil, which stands for a shell that exited 0.
