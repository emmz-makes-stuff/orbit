## 1.2 OrbStack: scratch machine `orbit-spike`, OrbStack 2.2.4

- `orb create --isolated --forward-ssh-agent --mount <dir> ubuntu orbit-spike` takes about 11.6s.
- **A mount with no DEST lands at `/mnt/mac/<dir>`, not at the same path.** `--mount SRC:SRC` puts it
  at the same path, writeable both ways. This was tested through `orb config set
  machine.<n>.mounts` + restart, for both a `/private/tmp/...` path and a `/Users/...` path. The
  create-time `SRC:DEST` form matches the docs and is checked in §9.
- Isolation holds. `/mnt/mac` contains only the mounts' own paths, `/Users` is absent until a mount
  creates it, `mac` fails with `dial: no such file or directory`, and the Mac host isn't reachable.
  HTTPS to the internet gives 200.
- `orbctl list -f json` → `config.mounts: [{source, destination?}]` in order, plus `isolated` and
  `forward_ssh_agent`. **This replaces `orbctl config get … mounts` and its comma parsing.**
- `orbctl run -m <n> -w <dir>` with no command (stdin piped) gives `$0=-bash` and a login shell in
  `<dir>`. A **missing `-w` dir silently falls back to `/`, exit 0.**
- With `ORBENV=CLAUDE_CODE_OAUTH_TOKEN`, the token reaches the shell. The control run without
  `ORBENV` shows it unset.
- `SSH_AUTH_SOCK=/opt/orbstack-guest/run/host-ssh-agent.sock`, and `ssh-add -l` in the VM lists
  `id_rsa`.
- `orbctl run … sh -c 'exit 3'` exits 3.
- **Still waiting on Emmz:** how the interactive shell feels (prompt, colours, Ctrl-C, resize,
  `exit`), via `orbctl run -m orbit-spike -w /Users/rendle/github/emmz/orbit-spike-ws`.

## 1.3 Keychain: throwaway item `orbit-spike`

- `printf 'add-generic-password -U -s … -a … -w <v>\n' | security -i` → exit 0. `-U` overwrites.
  `find-generic-password -w` returns the value.
- `security -i` passes through the inner command's exit code (a bad option returns 2).
  Not-found exits **44**, for both find and delete.
- `security -i` parses quoting, so tokens are limited to `[A-Za-z0-9_-]+`.
- No fallback is needed. `go-keychain` stays rejected.

## Design updates (Emmz approved)

- design.md Context, D3, D4, D5 and D6, ADR-0003, and tasks 2.1/4.1/5.1 now say: mounts are always
  `SRC:SRC`; the workspace path is `config.mounts[0].source` from the list JSON; paths with `:` or `,`
  are rejected; orbit only passes a `-w` it has resolved to lie inside the workspace; the token
  charset is `[A-Za-z0-9_-]+`; exit 44 means not found.
